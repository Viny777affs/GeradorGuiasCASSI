C
GERADOR DE GUIAS CASSI
Painel administrativo local para leitura de protocolos e geração de guias em PDF.
Versão 1.0.0
A aplicação lê os documentos PDF selecionados localmente, extrai os dados do protocolo, valida os procedimentos cadastrados e encaminha a geração das guias conforme as configurações escolhidas. Os documentos não são enviados para serviços externos.
Tecnologias
InterfaceHTML, CSS e JavaScript
Ponte localPyWebView
Leitura e PDFpypdf + ReportLab
ConfiguraçõesJSON local
Privacidade e segurança
O processamento ocorre no próprio computador. O histórico é gravado localmente para consulta administrativa. Os PDFs originais não são alterados e os arquivos gerados não sobrescrevem documentos anteriores.
